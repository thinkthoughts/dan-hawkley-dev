# Lifestyle Calendar

Prototype path: `danhawkley.dev/lifestyle/`

A Lifestyle Calendar is an organization of cues. The visible interface emphasizes the current period, observations, sessions, reading points, invitations, memory, active projects, and the period completion horizon. Exact dates remain available in JSON for astronomy, plots, archives, and retrieval.

## First period

**Leo A:** 2026-07-31 through 2026-08-30

## First projects

- Worksheet / Drawing: thirty two-sided sheets or index cards assembled as one drawing.
- Lifestyle Calendar Prototype: curated index page plus JSON scaffolding.
